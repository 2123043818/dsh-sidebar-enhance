# docs/

开发过程记录。**这些不是使用文档**（使用文档是仓库根目录的 `README.md`）。

保留它们的理由：里面记录了几次真实事故的根因和为什么那么修，
比"最终代码长什么样"更有价值 —— 例如为什么判定导航必须在 webview 层做、
为什么通道不能用长轮询、为什么结果必须装在 `data` 字段里。

| 文件 | 内容 |
|---|---|
| `changelog-and-sync-rules.md` | **先读这个**。v3→v10 修改记录 + 「怎么确认加载的是最新版」的规则 |
| `tab-dedupe-plan.md` | 一次点击冒出多个 tab 的根因分析（5 个来源）与修复方案 |
| `act-hang-fix.md` | act 点击后卡住 / 永挂的根因与修复 |

> ⚠️ 这几个文件里含**本机绝对路径**（形如 `F:\...`、`C:\Users\<用户名>\...`）。
> 若要公开发布，建议把路径泛化（改成 `<插件目录>`、`~/.dsh/...`）或直接删掉本目录。
